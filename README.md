# Saraswati's Kitchen Catalogue Page

Static GitHub Pages-ready website.

## Files
- `index.html` - main catalogue page
- `assets/brand/logo.jpeg` - brand logo
- `assets/catalog/*.jpg` - product images rendered from the catalogue PDF

## Publish on GitHub Pages
Upload the full contents of this folder to a GitHub repository, then enable Pages from Settings > Pages > Deploy from branch > main > root.
